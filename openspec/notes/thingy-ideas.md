# Thingy ideas

A running backlog of ideas for **thingies** — the small decorative SVG/CSS tiles on
the `/thingies` canvas. Jot an idea here when it strikes; pick one up later to build.

This doc is meant to be read and edited by both Iwan and Claude. When an idea gets
built, check it off here rather than deleting it, so the list doubles as a record of
what's shipped.

## How to use this doc

- **Add an idea** — append a new row to the table. Only `Idea` is required; a
  `Description` is optional (a one-line hint of what it draws / how it moves).
- **Build an idea** — use the `add-a-thingy` skill (or the contract in
  [`src/features/thingies/thingies/README.md`](../../src/features/thingies/thingies/README.md)).
- **Check it off** — once built, change `Done` from `[ ]` to `[x]` and put the tile's
  id (e.g. `0013-slinky-steps`) in the `Built as` column. Keep the row.
- **Keep the table append-only-ish** — don't renumber or reorder existing rows; just
  edit a row's `Done`/`Built as` when its status changes.

Status legend: `[ ]` = idea, not built yet · `[x]` = built and live on the canvas.
